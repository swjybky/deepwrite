# 文案与多语言

返回 [DESIGN.md](../DESIGN.md)。完整说明见 `apps/desktop/src/renderer/src/i18n/README.md`。

## 多语言

- 界面支持 `zh-CN` 与 `en-US`，`auto` 跟随系统。所有界面文字（标签、说明、空状态、toast、`aria-label`、`title`、原生菜单）都走 i18n，不在模板里写死中文或英文。
- 在 `i18n/messages/` 对应领域的中英文资源里加同名语义键，插值参数一致；组件里用 `createScopedTranslator("<命名空间>")`。
- 持续显示的选项与标签用 `computed` 或 getter 读 `t`，不在模块初始化时缓存译文，否则切换语言不更新。
- 用完整句子作为一个键，不拼接翻译片段。
- 不翻译用户内容：作品正文、用户命名、提示词、模型输出、文件路径、持久化枚举保持原值。
- 跨进程错误按 `ErrorPayload.code` 分支，不靠中英文错误文字判断。
- 语言资源计入启动体积预算，新增文案保持精简。改完运行 `pnpm lint:i18n`。

## 写法

- 简体中文，口吻平实直接，用作者熟悉的词（作品、章节、正文、素材、技能、智能体、团队），不用技术术语（“IPC”“payload”“Utility”）。
- 按钮写动作：“保存”“创建作品”“删除这一节”，不写“确定”“OK”。
- 错误说清发生了什么和怎么办：“模型连接超时，请检查网络或稍后重试。”不只写“失败”。
- 危险确认写明影响与能否恢复：“删除后可以在回收站还原。”
- 中文标点用全角。
- 英文用句首大写（Sentence case），不全大写（眉标由 CSS 转大写）。
