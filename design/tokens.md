# 设计变量

返回 [DESIGN.md](../DESIGN.md)。颜色用途见 DESIGN.md 的“颜色”一节，这里给推导方式、字号、间距、圆角、层级和动效。

## 颜色推导

`applyAppearanceThemeToDocument`（`renderer/src/composables/appearanceThemeRuntime.ts`）把背景色 B、前景色 F 按比例混合，写到 `<html>` 上：

| 变量 | 浅色（F 占比） | 深色（F 占比） |
| --- | ---: | ---: |
| `--surface-main` | 0（即 B） | 0 |
| `--surface-raised` | 1.8% | 5.5% |
| `--sidebar-surface` | 3.5% | 8%（半透明时 alpha 0.84） |
| `--surface-muted` | 4.5% | 9% |
| `--theme-line-soft` | 7.5% | 13% |
| `--surface-hover` | 8.5% | 14% |
| `--surface-selected` | 12% | 20% |
| `--theme-line` | 14% | 20% |
| `--text-tertiary` | 50% | 52% |
| `--text-secondary` | 67% | 72% |
| `--text-primary` | 100%（即 F） | 100% |

- `--accent` 为强调色原值；`--accent-soft` 为强调色 12%（深色 18%）透明度；`--accent-contrast` 按强调色亮度在 `#17191C` 与 `#FFFFFF` 中自动取。
- `--theme-background`、`--theme-foreground` 为原始背景、前景色，用于遮罩和阴影混色。
- 状态色在 `styles.css` 的 `:root` 定义：`--success #40845a`、`--warning #c28b35`、`--danger #a94f47`、`--danger-text #8f3e37`，`-soft` 版本为低透明度底色；深色主题改为与 `--surface-raised` 混合。
- 旧别名仍在用（`--line`、`--line-soft`、`--text`、`--text-soft`、`--text-faint`、`--hover`、`--selected`、`--sidebar`、`--editor`、`--focus`），都指向上面的主题变量。新代码直接用主题变量名。
- 写 `var(--x, #fallback)` 的后备值只是兜底，不能代替主题变量。

## 字体与字号

- 字体：`--ui-font`（界面）、`--editor-font`（正文、标题、正文类文本域，默认宋体系）、`--code-font`（路径、版本号、代码）。
- 字号基准：`:root` 的 `font-size` 是 `--ui-font-size`（默认 14px，可调 10–24）。**界面字号一律用 `rem`**，按“设计稿 px ÷ 14”换算，这样跟随 UI 字号缩放。正文用 `--editor-font-size`，代码用 `--code-font-size`。

| 场景 | rem | 14px 下 |
| --- | --- | ---: |
| 眉标、徽标 | 0.642857 – 0.714286 | 9 – 10 |
| 字段标签、按钮、辅助说明 | 0.785714 | 11 |
| 弹窗描述、小号正文、分段控件 | 0.857143 | 12 |
| 列表项、设置项说明、搜索框 | 0.892857 – 0.964286 | 12.5 – 13.5 |
| 设置项标题、正文 | 1 | 14 |
| 卡片标题 / 分组标题 | 1.07143 – 1.142857 | 15 – 16 |
| 弹窗标题 | 1.35714 | 19 |
| 设置面板标题 | 1.5 | 21 |
| 分析页标题 | 1.714286 | 24 |
| 设置页大标题 | 2.57143 | 36 |

- 字重：正文 400；标签与列表 540–590；标题 600–650；不超过 700。
- 大标题加 `letter-spacing: -0.02em` 左右；眉标大写加 `0.11em`。
- 行高：说明文字 1.45–1.65，正文类文本域 1.7。

## 间距

以 4px 为主节奏，常用值：2 / 4 / 6 / 8 / 10 / 12 / 14 / 16 / 18 / 22 / 24 / 28。

- 同组内元素 gap 6–8；字段之间 10–12；卡片之间 16；区块之间 24–28。
- 弹窗头 `20px 22px 15px`，内容 `20px 22px 23px`；设置卡片行 `14px 18px`；分析卡片 18px。

## 圆角

| 元素 | 圆角 |
| --- | ---: |
| 小徽标、行内标记 | 4–6 |
| 按钮、图标按钮、紧凑输入、导航项 | 7 |
| 输入框、搜索框、提示块 | 8–9 |
| 卡片、列表卡片、toast、分段控件外框 | 10 |
| 分析卡片、底部保存栏 | 12 |
| 设置卡片 | 13 |
| 弹窗、设置面板 | 15 |
| 胶囊徽标、开关 | 999 |

## 层级（z-index）

| 层 | 值 | 例子 |
| --- | ---: | --- |
| 页内吸顶 / 吸底 | 2 – 5 | 保存栏、表头 |
| 栏宽拖拽手柄 | 20 | `.pane-resizer` |
| 工作台弹窗遮罩 | 100 | `.dialog-backdrop` |
| `PopupSelect` 默认菜单 | 1000 | `menuZIndex` 默认值 |
| 浮层提示、小型删除确认 | 1600 | 上下文窗口提示、压缩面板 |
| 二级弹窗 | 2100 – 2400 | 长篇结构、伏笔、新建卷 |
| 二级弹窗内的菜单 | 2300 – 3200 | 必须高于所在弹窗 |
| toast | 10000 | `ToastHost` |

规则：弹窗里的 `PopupSelect` 必须设置 `:menu-z-index` 高于该弹窗遮罩；新弹层先在上表找位置，不随手写更大的数。

## 动效

- 时长 120–180ms，`ease`；开关、悬停、颜色过渡 150ms，栏宽变化 180ms。
- 只过渡颜色、透明度、`transform`、栏宽；不过渡 `height: auto` 造成布局抖动。
- 全局 `prefers-reduced-motion: reduce` 会把动画与过渡压到 0.01ms，无需逐个处理。
