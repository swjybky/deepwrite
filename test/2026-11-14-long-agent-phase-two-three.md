# 长篇智能体第二、三期验收

## 目标与成功标准

读取护栏、全文检索、范围读取与写作上下文规则可用；连续性文件和账本由一张卡审批、原子落盘；旧参数和旧会话继续可用，团队模板默认禁用。

## 环境

macOS arm64，Node 24.19.0，Electron 42.5.0；临时目录与合成书，生产 Core Utility 构建入口；未修改真实作品或模型配置。
真实模型使用开发配置，同模型指纹 `6afda537d87d3803`；对照为本轮实施前（一期结束）源码快照与当前源码，短超时预跑中断后统一探针时限，正式对照各场景留存一组。

## 步骤与命令

- L1：工具经 Pi 参数校验；覆盖重复读取、实际剪枝通知、Unicode 范围、检索、缺失元数据、契约拒绝、旧流程、原子失败与确定性事务竞态。
- L2：`pnpm typecheck`、边界检查、构建、`pnpm smoke`；补充审批队列 39 项测试、Vue 类型检查与 ESLint；Electron UI 与 Core Utility 探针。
- L3：`pnpm verify` 通过，1,132 个测试文件，7,469 项通过、1 项跳过；测试耗时 859.50 秒。随后补测拒绝前序及重复接受两个审批边界。
