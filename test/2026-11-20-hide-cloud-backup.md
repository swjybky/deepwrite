# 临时隐藏云端备份验证

## 目标与成功标准

旧配置已开启云端备份时，侧边栏和设置的“更多功能”均隐藏该项。调整其他功能的顺序仍可保存，并保留旧备份偏好。

## 环境

macOS，Electron 开发版，隔离用户目录和合成配置。

## 步骤与命令

1. L1 运行功能列表、通用设置、资源广场及设置契约的定向 Vitest，检查改动文件的 ESLint 和 Prettier。
2. L2 用 `pnpm dev` 启动隔离开发版，运行 `pnpm lint:boundary`、Electron 多语言冒烟和 Renderer 类型检查。
3. 旧配置中开启云端备份，打开[侧边栏更多功能](2026-11-20-hide-cloud-backup/01-侧边栏更多功能.png)和[设置更多功能](2026-11-20-hide-cloud-backup/02-设置更多功能.png)。
4. 将双端同步上移，检查[排序结果](2026-11-20-hide-cloud-backup/03-调整顺序后.png)、保存数据和[设置列表底部](2026-11-20-hide-cloud-backup/04-设置列表底部.png)。

## 结果

28 项定向测试和多语言桌面冒烟通过。两处入口均隐藏云端备份，双端同步仍可见。排序成功保存，旧备份偏好仍为开启。

Renderer 类型检查在工作区并行修改的长篇章卡测试中报错。本次改动文件无类型报错。

## 未覆盖与后续

桌面验收覆盖 macOS 开发版。
