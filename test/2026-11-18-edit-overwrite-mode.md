# 编辑工具的全文覆盖模式

## 目标与成功标准
- 所有原先使用布尔覆盖开关的编辑工具只声明可选字符串枚举 `overwrite_mode: "replace_all"`。
- 缺失或错误模式不能覆盖非空内容。显式替换或清空仍遵循各工具现有的读取、版本及审批规则。

## 环境
- 2026-11-18，macOS，项目锁定的 Pi 运行时。测试用合成文稿和模型响应。

## 步骤与命令
- 先更新覆盖回归测试，确认短篇、剧本及长篇用例在旧实现上失败。
- L1：定向运行编辑工具、预检、提示词及桌面 Agent 请求集成测试，检查相关文件的 ESLint 和 Prettier。
- L2：运行类型检查与边界检查。通过 Pi SDK 请求回调离线检查四种协议的序列化。

## 结果
- 28 个测试文件、299 项通过，覆盖短篇、长篇、剧本、学术写作、剧本杀、素材与技能条目、库介绍及批量写入。
- 全量类型检查、相关文件的 ESLint 和 Prettier、Renderer 边界检查均通过。
- Pi 拒绝布尔值、数字、错误字符串和异常数组；字段缺失或被视作省略时，非空目标仍拒绝全文覆盖。批量中任一项缺模式时整批不提交。
- OpenAI Completions、OpenAI Responses、Anthropic Messages 和 Gemini 原生请求均保留可选字符串枚举。生产代码和运行时提示词中已无旧参数，历史测试记录保留原样。
