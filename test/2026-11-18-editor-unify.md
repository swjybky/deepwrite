# 编辑区样式统一

## 目标与成功标准
- 短篇、剧本、学术写作和剧本杀使用长篇的正文、工具栏与切换按钮主题色。
- 移除共用编辑区顶层章节标签；正文、状态和写作指引等关联文件切换独占顶部一行。
- 编辑／预览紧跟操作按钮，窄栏下不换行，空间不足时横向滚动。

## 环境
- macOS，Electron 42；独立临时 userData、实际 Vue 组件、四类合成文稿，不访问真实作品。
- 基线先采集；修正探针布局后，用保留的改前组件与改前 CSS 值重新渲染同条件基线。

## 步骤与命令（L1 / L2）
- 定向 Vitest：RightEditorPane、ScopedGlobalStyles、useMysteryDocument。
- 改动 Vue / TS 的 ESLint、全部改动文件 Prettier 和 git diff --check。
- Electron capturePage：浅／深色 1200×900、14px；浅／深色 1000×680、24px。
- 额外将四类编辑面板缩到 280px，以各按钮中心纵坐标验证工具栏保持单行。

## 结果
- 21 项测试通过；ESLint、Prettier 与差异检查通过。
- 四组截图均完成：背景跟随主题；关联文件独立一行；操作按钮没有掉到下一行。
- 280px、24px 下四类工具栏按钮均保持单行；不足部分可横向滚动。
- [截图与采样](2026-11-18-editor-unify/)，compare 图左为改前、右为改后。
