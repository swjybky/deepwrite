# main 工具参数迁移验证

## 目标与成功标准

- 将短篇、长篇、剧本、资料库、团队管理及拆书现有模型工具的布尔入参替换为字符串枚举。
- 验证默认读取、覆盖保护、分组删除范围、团队审阅、拆书暂存和旧数据读取。

## 环境

基于 `main` 的 `5b2afaea` 创建隔离工作区，使用合成夹具和 Pi SDK。依赖从本地缓存安装。

## 步骤与命令

- L1 定向验证工具参数与四种协议的发包结构，共五个测试文件。
- L3 `DEEPWRITE_TEST_MAX_WORKERS=6 pnpm verify`。

## 结果

- 49 项定向测试通过，覆盖 OpenAI Chat Completions、OpenAI Responses、Anthropic Messages 和 Gemini 原生协议的发包结构。
- 全量验证通过。1,141 个测试文件中 7,563 项通过，1 项跳过，类型、Lint、边界、本地化和桌面构建均通过。
