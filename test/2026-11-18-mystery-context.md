# 剧本杀上下文验证

## 目标与成功标准

- 从剧本杀作品菜单的「管理」打开「剧本杀上下文」。目录和「真相与统筹」概览只列阶段文稿。
- 新作使用同一初始模板，编辑后独立保存到各自的 `AGENTS.md`。支持手动保存、切换页签和关闭时自动保存。

## 环境

- macOS Electron，使用同仓库的改前与改后构建、独立临时配置和两部合成作品。

## 步骤与命令

- L1 `pnpm exec vitest run` 定向运行资源树、工作台性能、上下文、剧本杀存储和智能体测试，另运行定向 ESLint 和 Prettier 检查。
- L2 `pnpm typecheck`、`pnpm lint:boundary`、`pnpm lint:i18n`。用 `electron-vite build --outDir` 隔离构建，运行 Renderer 冒烟及体积检查，并通过桌面界面读写真实临时文件。

## 结果

- **通过** 9 个测试文件共 29 项。类型、格式、边界、多语言与 Renderer 预算检查通过。
- **通过** 两部新作初始内容相同。手动保存、切换页签和关闭均写回当前作品，另一部内容保持独立。外部编辑产生冲突后可以重新载入，旧标题和正文按原样读取。
- **通过** 目录入口已迁移到管理页。浅色与深色在 1440×900／14px 和 1000×680／24px 下无横向溢出，输入框与底部提示没有重叠。
