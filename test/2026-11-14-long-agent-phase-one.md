# 长篇智能体第 0、1 期验证

## 目标与成功标准
- 本轮落实方案 4.1–4.5；成员能定位前一成员新建的章卡，只读成员不接收写入规则。
- 首轮与追问都呈现五阶段当前位置；焦点快照只传定位，发送不依赖焦点正文读取。
- 世界观目录每类最多 200 项、总计 2,000 项；旧正文快照与旧版中英角色提示词兼容。

## 环境
- macOS，Node 24.19.0，pnpm 11.7.0；共享 main 工作区已有其他未提交改动，本轮未提交或推送。
- 全部书籍与正文为合成夹具；[夹具](2026-11-14-long-agent-phase-one/fixture.json)。未改作品磁盘结构。

## 步骤与命令
- L1：开工前 7 文件 56 测试通过；新增位置快照、同名/省略项定位、成员交接、无正文读取发送及契约兼容回归。
- L1：`pnpm vitest run <定向测试文件>`；成员交接、五阶段快照、发送预检及旧版提示词兼容均通过，最终由全量验证覆盖。
- L2/L3：`pnpm verify`（格式、类型、lint、全部测试、构建）；`pnpm smoke`；Electron `utilityProcess.fork(out/main/utilities/agent-entry.js)` 五阶段焦点探针。
- 脚本回放：按固定工具调用序列核对新建一卷三章、写章、提交连续性、委派写章，工具参数经过 Pi 校验。
- 真实模型：临时 Electron 配置副本经 ModelConfigStore 解析；系统安全存储不可用，未进入模型调用。

## 结果
- 通过：成员读取新章卡并提交正文；只读成员仅有 list/read/素材查询，系统规则不含创建、修改、账本或审批小节。
- 通过：五阶段快照、同名人物 id 定位、目录省略条目定位、焦点发送零 readDocument、200/201 与总量边界、新旧快照校验。
- 通过：旧版中英文角色提示词仍识别为内置；新提示词按最近检查点与未提交章节取材。
- [四场景回放](2026-11-14-long-agent-phase-one/scripted-baseline.json)只记录工具能力、提示词组装字符数与读取结果字符数；token 字段留空，不用于推断模型性能。
- 通过：`pnpm verify`，1,127 文件、7,440 测试通过、1 项跳过；测试用时 862.75 秒。格式、类型、三项 lint、构建与 Renderer 体积预算均通过。
- 通过：`pnpm smoke`；[生产构建入口焦点探针](2026-11-14-long-agent-phase-one/desktop-context-probe.json)五阶段均接收成功、完成回复并正确呈现位置。
