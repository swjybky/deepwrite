# 创作空间工具用例

开始前对照 MCP 实际 `tools/list` 或当前会话发现的工具，以及 [外部接口契约](../../../../packages/contracts/src/external-control/tools.ts) 和 [智能体工具装配](../../../../packages/pi-runtime-adapter/src/run-tools.ts)。按实际提供的工具更新本轮清单。管理工具按操作记录，内置工具按作品类型记录。当前 MCP 接口含下列 24 个工具。

## MCP

| 工具 | 调用与通过条件 |
| --- | --- |
| `get_app_status` | 返回版本和 `rendererReady`，并在收尾核对待测运行没有遗留。 |
| `list_works` | 列出本批次五个作品，核对类型过滤。 |
| `get_work` | 获取各作品目录，用返回的 ID 定位文档和结构变化。 |
| `open_in_app` | 从工作区打开合成作品，确认可见或可发起运行，剧本杀单列。 |
| `manage_work` | 创建五类作品。在专用副本上验证重命名、复制、删除、恢复。核对列表和复制文本。 |
| `read_document` | 获取完整正文和版本，用较小页长验证 `nextOffset` 续读，再回读智能体产物。 |
| `write_document` | 用最新版本写合成校验词。用旧版本写不同内容，期望 `external.stale_revision` 且原文不变。 |
| `search_text` | 分别查作品和合成资料库，核对命中文档或条目，另测一个未命中词。 |
| `manage_document` | 在短篇、剧本或学术合成作品的专用小节验证创建、改名、移动、复制及删除。用目录顺序和回读确认。学术恢复后回读指引、正文、节末状态。 |
| `run_agent` | 各类作品发起普通模式。对补测沿用 `sessionId`，团队场景指定 `team` 并核对实际模式。 |
| `get_agent_run` | 逐一看到终态并取工具轨迹。保留运行 ID、会话 ID 和产物回读证据。 |
| `answer_agent_question` | 让合成任务用 `ask_user_question` 询问两种测试落款。观察 `waiting_for_input` 并用返回的选项 ID 提交预定答案，核对运行继续和结果一致。 |
| `stop_agent_run` | 在确定仍在运行的专用合成任务上停止，后续状态为 `stopped`。可在固定问题等待阶段执行。 |
| `list_trash` | 只匹配本批次已删除的对象和对应 `trashId`。 |
| `restore_trash_item` | 用对应 `trashId` 恢复，重新解析 ID 并回读。活动运行可能返回 `external.busy`，等本批次运行结算再试。 |
| `manage_library` | 建合成素材库和技能库供绑定。用专用备份库验证重命名、复制、删除和恢复。 |
| `list_libraries` | 用类型过滤核对新库及分组。 |
| `get_library` | 用真实返回的目录 ID 定位测试条目，并核对移动及恢复。 |
| `manage_entry` | 创建校验条目，验证改名、移动到同域的测试库或可用分组、复制及删除。对应恢复后回读。 |
| `read_entry` | 读取合成条目全文、版本，必要时续页。 |
| `write_entry` | 带最新版本改写合成条目，回读并核对旧版本写入被拒绝。 |
| `list_agent_teams` | 先列团队，记下该作品类型启用状态，再取本批次团队的设置和版本。 |
| `manage_agent_team` | 创建、改名合成团队。启用和停用只在隔离测试配置或该类型原先没有启用团队时验证，核对状态后恢复原设置。删除仅限本批次已停用团队，并验证能恢复。 |
| `save_agent_team` | 读本批次团队的完整设置和版本，修改测试成员指令并保存，再读取校验。 |

绑定用作品设置提供的入口，只绑定本批次新建的素材库、技能库及测试团队。用 `get_work` 核对 MCP 返回的库绑定。没有绑定或隔离条件时记录具体阻塞，继续其余用例。

## 内置智能体

对各作品分别读取 `toolUsage.byTool`。同名工具在不同作品的适配层可能不同。删除只针对本轮专设的临时对象，先确认其内容和唯一 ID。需要连续修改同一部作品时，等待前一提案保存再读写下一份。

| 工具 | 实测路径与通过条件 |
| --- | --- |
| `read`、`edit` | 五类都测。读合成来源和目标，经智能体提交修改，用 MCP 回读校验词和内容。 |
| `create`、`delete` | 五类各设可删除的新对象。短篇用小节，剧本用单集，学术用方法附节，长篇用临时章卡，剧本杀用自定义搜证轮次。先确认创建已保存，再调用删除，核对仅该临时对象消失。 |
| `list` | 长篇列剧情或章节目录，核对实际章节 ID。短篇、剧本用其实际提供的 `read` 目录能力。 |
| `search` | 长篇、学术、剧本杀各查同一作品里的已落盘校验词。剧本杀另用 `player_visible` 核对搜证线索的人群边界。 |
| `query_linked_material_entries` | 各类已绑测试库的作品查一个独有词，并实际读取命中条目，核对返回标记。 |
| `load_skill` | 各类已绑测试技能的作品按名称加载带独有标记的合成技能，验证读到了正确内容。 |
| `ask_user_question` | 各类中有该工具时复用固定落款问题，核对等待、MCP 答复和继续运行。 |
| `propose_continuity_commit` | 长篇在支持账本提交的阶段做一章合成样本。完整读取已保存正文，按实际候选触点据实提交，无候选用空列表。用 `get_work.continuity` 核对账本存在且与本章对应。 |
| `spawn_subagent` | 使用已绑定且可用的合成团队，主智能体派一名成员做只读摘要，核对团队模式、派遣及子工具轨迹。 |
| `web_search`、`web_fetch` | 在已挂载对应工具、且允许联网的合成任务上测。用公开、非私密主题，核对搜索命中与网页读取结果。工具未挂载时记录所缺设置或提供方能力。 |
