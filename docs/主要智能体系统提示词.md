# 主要智能体系统提示词

适用范围：短篇、剧本、长篇三个创作智能体，以及素材库、技能库两个资料库智能体。“更多功能”里的智能体（聊天、各类分析）不在此范围，仍走扩展智能体服务的档案提示词。

## 语言选择

- 设置 → 常规 → 语言有三档：跟随系统（默认）、中文、英文。
- Main 用 `resolveAppLocale` 把设置解析成 `zh-CN` 或 `en-US`（跟随系统时，系统语言以 `zh` 开头为中文，其余为英文），每次运行经 `agent.prompt` 的 `promptLocale` 交给 Agent。Renderer 的 `session.prompt` 载荷不变。
- 切换语言后，下一次发送即生效，无需重启。

## 分层

每次运行的系统提示词由下面几层依次拼成：

| 层 | 内容 | 能否编辑 | 位置 |
| --- | --- | --- | --- |
| 基础准则 | 身份、优先级、事实来源、能力边界、外部内容、回复语言 | 不可编辑 | `pi-runtime-adapter/src/prompts-base.ts` |
| 角色提示词 | 角色定位、工作方式、建设链路、质量标准、回复要求 | 设置页可编辑 | `contracts/src/agent-prompts/` |
| 工作区规则 | 作品目录、当前阶段、对象定位、读写规则、资料库范围 | 不可编辑 | `prompts-writing*.ts`、`prompts-long-rules.ts`、`prompts-library.ts` |
| 写入审批方式 | 自动保存或用户审批 | 不可编辑 | `write-approval.ts` |
| 剧本格式 | 场景标题、△ 动作行、OS/VO 等硬约束（仅剧本） | 不可编辑 | `script-agent-settings.ts` |
| 联网搜索 | 仅在本轮开启联网时追加 | 不可编辑 | `web-search/prompt.ts` |

长篇另在末尾追加“本轮长篇工具边界”（实际工具清单）。

工具名称、对象 id、参数用法这些“规则”全部放在不可编辑层：用户改写或清空角色提示词，也不会丢失工具用法；团队成员（子智能体）复用同一份工作区规则。角色提示词只写“怎么当好这个角色”。

## 内置提示词与自定义提示词

- 每个角色提示词都有中文和英文两份，`agent-prompts/` 中按 `zh-CN` / `en-US` 存放，两份的章节一一对应（有测试检查）。
- 磁盘上保存的提示词如果等于任一语言或任一历史版本的内置提示词，就视为“未自定义”，Main 按当前语言返回内置版本。历史版本以 SHA-256 指纹记录在 `apps/desktop/src/main/builtin-agent-prompts.ts`。
- 用户改过的提示词原样保留，不随语言切换；“恢复默认”后重新跟随语言。
- 以后修改内置提示词时，把旧版本的指纹加入 `LEGACY_PROMPT_FINGERPRINTS`，否则已安装用户会被当成“已自定义”，收不到新版本。

## 仍为中文的部分

以下内容不属于系统提示词，本次没有改动，英文模式下仍是中文：每轮用户消息里的固定上下文（作品快照、AGENTS.md 标题、长篇目录与导航）、工具说明与工具返回、上一轮修改的处理结果，以及资料库管理工具、团队提示词管理工具的附加说明。
