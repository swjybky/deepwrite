# 作品管理弹窗统一设计

2026-11-18 定稿。范围：作品菜单“管理”打开的弹窗，覆盖短篇、剧本、长篇、剧本杀、学术五类作品。

## 1. 现状问题

| 作品 | 组件 | 外壳尺寸 | 导航 | 子表单 |
| --- | --- | --- | --- | --- |
| 短篇 / 剧本 | `PlotStructureDialog.vue` + `plot-structure-dialog.css` | 宽 1040，`max-height` 随内容变 | 顶部三标签（人物结构 / 情节结构 / 上下文） | 叠加子弹窗 |
| 长篇 | `LongStructureDialog.vue` + `LongStructureManager.vue` | 宽 1040，`max-height` 随内容变 | 大卡片三标签 + 第二层分段（世界观类别 / 人物类型） | 叠加子弹窗，主弹窗隐藏 |
| 剧本杀 | `LongStructureDialog` 插槽 + `MysteryStructureManager.vue` | 同长篇 | 一排 `aria-pressed` 按钮（六项） | 各自实现 |
| 学术 | `AcademicFrameworkDialog.vue` | 宽 760，高随内容变 | 自绘顶部标签 | 内嵌表单与内嵌确认条 |

五类做的是同一件事——管结构、管设置、管上下文——却有四套外壳、四种导航、三种按钮和两种增删改方式；切换标签时弹窗高度跳动。

## 2. 目标结构

所有作品共用一个外壳 `BookManagementDialog`，按同一份配置渲染：

```
┌─────────────────────────────────────────────────────────────┐
│ 作品类型·管理                                          [×]  │ 头部
│ 《书名》                                                    │
├─────────────────────────────────────────────────────────────┤
│ 名称  书名                                     [修改名称]   │ BookManagementName
├──────────────┬──────────────────────────────────────────────┤
│ 结构         │ 分区标题                        [主操作]     │
│  · 分区 A    │ 一句说明                                     │
│  · 分区 B    │ ─────────────────────────────────────────── │
│ 设置         │ 分区内容（只有这里滚动）                     │
│  · 分区 C    │                                              │
│ 上下文       │                                              │
│  · X上下文   │ 脚注                                         │
├──────────────┴──────────────────────────────────────────────┤
│ 作品级操作（可选，如长篇“同步旧版本 / 解决冲突”）           │ 底部
└─────────────────────────────────────────────────────────────┘
```

### 2.1 固定尺寸（硬性）

- `width: min(960px, calc(100vw - 48px))`，`height: min(680px, calc(100vh - 48px))`，用 `height` 不用 `max-height`，用 px 不用 rem：切换分区、加载、空状态、列表长短、UI 字号 10–24px 下外框尺寸都不变。
- 只有右侧内容区滚动；头部、名称行、左侧导航、底部固定。左侧导航项过多时导航自身滚动。
- 打开新建 / 编辑 / 删除 / 转换等子弹窗时，主弹窗保持原尺寸和位置，子弹窗叠在上方；不隐藏、不缩放、不换位。
- 加载中、保存中、错误态都在内容区内显示，不改变外框。

### 2.2 配置结构

每类作品只提供一份分区配置，外壳不认识具体业务：

```ts
type BookManagementGroup = "structure" | "settings" | "context";

interface BookManagementSection {
  id: string;
  group: BookManagementGroup;
  label: string;        // 左侧导航文字
  title?: string;       // 分区标题，缺省用 label
  description?: string; // 分区说明一句话
}
```

分组固定顺序：**结构 → 设置 → 上下文**，没有分区的组不显示组名。上下文永远是最后一项。

| 作品 | 结构 | 设置 | 上下文 |
| --- | --- | --- | --- |
| 短篇 | 人物结构、情节结构 | — | 短篇上下文 |
| 剧本 | 人物结构、情节结构 | — | 剧本上下文 |
| 长篇 | 世界观类别、人物类型 | 功能设置 | 小说上下文 |
| 剧本杀 | 盘面、设定文档、角色、幕次、搜证轮次（以现有集合为准） | — | 剧本杀上下文 |
| 学术 | 框架阶段 | 写作设置（类型、引用格式） | 学术上下文 |

长篇原来“基础结构”里的两层标签拆平为两个结构分区，不再有第二层分段。

### 2.3 内容区统一样式

- **分区头：**标题 + 一句说明，右侧放该分区的主操作（如“新建情节结构”“新建阶段”“从其他作品载入世界观”）。去掉 `LONG-FORM STRUCTURE`、`CHARACTER STRUCTURE` 这类英文眉标。
- **条目列表：**一行一个条目，统一列序：启用开关（有则显示）→ 名称 + 说明 + 标识（默认 / 内置 / 自定义）→ 操作（上移、下移图标按钮，编辑，删除）。同一套行高、间距、按钮尺寸、禁用态。
- **设置项：**左文案（名称 + 说明）右控件的设置行，同设置页卡片内分隔行。
- **上下文：**五类共用 `WritingContextPanel` 的外观：说明、字数、填满内容区的文本域、右下保存。长篇保留自己的字数上限与保存逻辑，只统一外观。
- **增删改：**一律用叠加子弹窗（`design/dialogs.md` 默认宽度），不用内嵌表单或内嵌确认条。
- 按钮、开关、选择框只用全局控件类（`design/buttons.md`、`design/forms.md`），不保留 `academic-*-btn` 等自绘控件。

## 3. 不改的部分

- 数据、契约、存储与保存流程不变；各分区现有的校验、上限、冲突处理照旧。
- 作品菜单顺序与绑定弹窗不变（见 `BookActionMenu.vue`、`BookBindingsDialog.vue`）。

## 4. 验收

- 五类作品打开管理弹窗，在相同窗口下外框像素尺寸完全一致；逐个切换分区、打开子弹窗，外框尺寸与位置不变。
- 浅色、深色、最小窗口 1000 × 680、UI 字号 24px 下不溢出、不裁切，只有内容区滚动。
- 各分区原有操作（新建、编辑、排序、启停、删除、改名、保存上下文、长篇同步旧版本 / 解决冲突）仍可用。
