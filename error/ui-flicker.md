# 即时操作闪烁与输入被锁

返回 [ERROR.md](../ERROR.md)。

**症状：**点开关后整页控件变灰再恢复；按钮文字切换时后续按钮横移；自动保存时打的字被吞、光标回退。

**根因：**

- 页面级 `saving` / `loading` 绑到无关控件的 `disabled` 或 `v-if`，一次往返全部闪一次。
- 状态文案宽度不同且未预留占位，触发重排或换行。
- 保存后刷新流程锁住编辑器（只读）或用旧内容覆盖光标位置。

**处理：**

- 开关类乐观更新，再用 Main 快照收敛，失败 toast 并恢复；递增序号丢弃过期回复（参考 `useAgentTeamCatalogCoordinator.setAgentTeamEnabled`）。
- 短暂保存锁与“不可用”分开传；状态文案用不可见占位撑出最大宽度。
- 自动保存后的刷新不锁输入、不重置光标。

**预防：**按 [design/feedback.md](../design/feedback.md) 的“验证”逐帧采样；完整案例见 `docs/前端闪烁问题排查与修复.md`。
