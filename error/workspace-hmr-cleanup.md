# 工作台热更新后目录或会话不可用

返回 [ERROR.md](../ERROR.md)。

**症状**　热更新 `WorkspaceShell.vue` 后，提示 `Catalog index store has been disposed.`，创作目录或长篇列表消失。会话持久化调度器也曾在热更新后关闭，导致退出等待保存超时。

**根因**　Vue 热更新重建工作台，Pinia 存储继续存活。旧组件的清理曾释放目录索引与长篇存储，也可能清除新组件的布局元素或关闭新组件配置的保存队列。

**处理**　目录索引和长篇存储由 Pinia 作用域释放。工作台同步清理当前布局和长篇会话，晚到的导航、刷新结果退出。会话保存适配器的清理在开始前和刷新完成后核对归属。已出现此错误的旧开发窗口重启一次。

**预防**　工作台改动覆盖旧组件卸载、新组件复用同一个 Pinia、旧请求晚到的顺序。启动先完成目录加载再允许焦点刷新。热更新后从侧栏重新打开样书，验证实际正文可读。组件重挂载回归见 `App.workspace-lifecycle.test.ts`，会话持久化回归见 `conversationStore.test.ts`。
