# 短篇流畅，长篇普通章节与右列表分栏拖动更慢

**症状**　普通章节也有额外开销，显示章卡右列表时更明显。

**根因**　完整工作台将实时外栏宽度传给长篇工作区模块。编辑器组件上的 `v-show` 让可见正文随模块一起更新。长篇容器查询增加样式计算，列表模式下的尺寸监听还会在布局完成后改写内部 grid 宽度。

**处理**　外栏实时宽度只供工作台 grid 和共享分隔线组件读取。长篇用原生容器控制编辑器可见性。内栏由 CSS grid 计算列宽，把手在聚焦和调整时更新可访问范围。[修复验证](../test/2026-11-20-unified-pane-resize.md)

**预防**　从完整工作台拖真实分隔线，检查工作区与编辑器更新次数、列表每次宽度变化的布局次数及慢帧比例。固定文本、聊天和展开目录，分别测普通章节与列表页。修改容器查询前后比对窄栏位置和尺寸。
