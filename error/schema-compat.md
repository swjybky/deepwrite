# 持久化 schema 变更不兼容

返回 [ERROR.md](../ERROR.md)。

**症状：**手机同步报“该作品正在写入、已发生新修改或结构不兼容”；删除字段后用户旧作品打不开或显示无效。

**根因：**

- deepwrite-app 手工镜像桌面端的严格 schema；桌面新增字段而手机镜像未改，手机拒收整份清单或索引。
- strict schema 删除字段，带旧字段的已有数据整体校验失败。

**处理：**

- 改作品清单、长篇清单、长篇索引或同步模块时，同一改动内同步 deepwrite-app 的镜像（两端共用模块须逐字节一致），两端一起发版。
- 删除或改名字段要有迁移或兼容读取，不直接让旧数据失效。

**预防：**测试覆盖“旧数据读入”和“新数据经手机端往返后字段保留”。
