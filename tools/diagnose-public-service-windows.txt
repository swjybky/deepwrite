DeepWrite 1.7.1 Windows 网络诊断工具

使用步骤
1. 先打开出问题的 DeepWrite，保持应用运行。
2. 将 ZIP 完整解压到一个可写的新文件夹，不要直接在压缩包里运行。
3. 双击 diagnose-public-service-windows.cmd，无需管理员权限或另装 Node.js。
4. 等待约 10～30 秒。结果保存在同一文件夹的 network-result-数字.json。
5. 将这个 JSON 文件发回排查即可，不需要提供密钥或服务地址。

如果提示找不到 DeepWrite.exe，将已安装的 DeepWrite.exe 拖到 CMD 文件上再运行。
如果没有生成 JSON，请保留窗口提示并发回。

工具读取实际安装包版本和编译后的公共服务配置，检测 DNS、HTTPS 及 Windows
系统网络连接；只查询公开模型接口，不携带 API 密钥，不上传诊断结果。
结果只包含版本、检查时间、配置是否存在、连接状态和经过筛选的错误代码，
不会输出服务地址、IP、密钥、代理地址或文稿内容。

工具不修改安装包、书稿、应用设置、系统代理、证书或 PowerShell 执行策略。
诊断子进程使用自己的临时运行环境，不改变已打开的 DeepWrite 进程环境。

验证范围：已通过脚本测试、真实 1.7.1 Windows 安装包读取和本机运行时实跑。
Windows 启动器及系统网络探测的原生现场结果需要在受影响电脑上确认。
